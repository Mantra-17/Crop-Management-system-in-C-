## 🌾 Overview

The Crop Management System is a console-based application designed to help farmers make informed decisions about crop cultivation, maintain detailed records, estimate profits, diagnose common crop problems, and access information about agricultural loans and support services. The system combines agricultural knowledge with data management to provide a comprehensive tool for modern farming practices.

## ✨ Features

### 1. Crop Determination
- Recommends suitable crops based on:
  - Season selection (Summer, Monsoon, Winter)
  - Soil type analysis (Red, Black, Desert, Forest)

### 2. Farmer Record Management
- Add and store comprehensive farmer records including:
  - Personal information
  - Crop details
  - Land area
  - Expected yield
  - Cost breakdown (seeds, labor, fertilizers, pesticides)
- Display all records in a tabular format
- Search records by crop type
- Update yield quantities

### 3. Profit Estimation
- Calculate potential profits based on:
  - Expected yield
  - Market prices
  - Production costs
- Save profit estimations to individual farmer files

### 4. Crop Problem Diagnosis
- Interactive diagnosis of common crop issues:
  - Yellowing of leaves
  - Wilting of plants
  - Pest attacks
  - Stunted growth
  - Leaf spots
- Provides detailed explanations and solutions

### 5. Loan Awareness Guide
- Information about various agricultural loan types:
  - Crop loans
  - Equipment loans
  - Irrigation loans
  - Land development loans
  - Animal husbandry loans

### 6. Contact Information
- Comprehensive list of agricultural support services:
  - Krishi Vigyan Kendra
  - Agricultural officers
  - NABARD
  - PM Kisan helpline
  - Specialized agricultural helplines

### 7. Multi-session Support
- Ability to switch between up to 10 different working sessions

## 🏗️ Class Structure

- **CropDetermination**: Recommends crops based on seasonal and soil type data
- **RecordKeeper**: Manages farmer and crop data storage and retrieval
- **ProfitEstimator**: Calculates potential profits based on costs and market prices
- **CropProblemDiagnosis**: Diagnoses common crop problems and suggests solutions
- **LoanAwarenessGuide**: Provides information on various agricultural loan options
- **ContactInfo**: Offers contact details for agricultural support services

## 🚀 Usage

1. Start the application
2. Select from the main menu options:
   - Crop determination based on soil and season
   - Add farmer records
   - Display all farmer records
   - Search farmers by crop
   - Update crop quantity
   - Estimate profits
   - Diagnose crop problems
   - Access loan information
   - Get help center contacts
   - Switch between sessions
